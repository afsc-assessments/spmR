# Canonical example directories

The package documentation and tests are curated around these two directories:

- `examples/atka`: canonical detail output workflow (`spm.dat`, `spm_detail.csv`)
- `examples/BSRE_AI`: canonical summary output workflow (`spm_summary.csv`)

Other directories in `examples/` are historical or species-specific archives and
are not guaranteed to stay synchronized with vignettes/tests.
