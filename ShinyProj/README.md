# Fisheries Projection Analysis App

Interactive Shiny app for analyzing fisheries projection data with multiple alternatives.

## Quick Start
1. `source("setup.R")` - installs required packages
2. `shiny::runApp("app.R")` - launches the app
3. Upload your percentiles.out file in the app

## Features
- Multi-alternative projection analysis
- Interactive 4-panel plots (Catch, SSB, F, Total Biomass)
- Reference line toggles (ABC, OFL)
- Data export capabilities
